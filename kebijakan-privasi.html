Kebijakan Privasi - Satu Titik

Nama paket: com.aurenza27.satutitik
Pengembang: AURENZA27
Terakhir diperbarui: 14 November 2026

Aplikasi "Satu Titik" dibuat untuk hiburan semata. Kebijakan ini menjelaskan data apa yang diproses aplikasi dan bagaimana data tersebut digunakan.

1. Data yang kami kumpulkan

Kami tidak meminta Anda membuat akun dan tidak mengumpulkan data pribadi di server kami. Nama, tanggal lahir, atau data lain yang Anda ketik pada menu-menu di dalam aplikasi hanya diproses di perangkat Anda untuk menampilkan hasil.

2. Penyimpanan di perangkat dan mode offline

Aplikasi menyimpan pengaturan (misalnya bahasa, tema, status musik dan volume) serta riwayat hasil di penyimpanan lokal perangkat Anda. Data ini tidak dikirim ke server kami. Aplikasi juga menyimpan salinan dirinya di perangkat agar dapat dibuka tanpa internet. Bila Anda mengirim saran saat tidak ada internet, pesan disimpan sementara di perangkat dan dikirim otomatis ketika internet tersambung kembali. Anda dapat menghapusnya dengan menghapus data aplikasi atau mencopot pemasangan aplikasi.

3. Layanan pihak ketiga

  • Kotak saran (Web3Forms): jika Anda mengirim saran lewat kotak saran, isi pesan Anda dikirim melalui layanan Web3Forms kepada kami. Jangan menulis data pribadi atau sensitif di pesan tersebut.
  • Waktu server (WorldTimeAPI): aplikasi dapat mengambil waktu UTC dari layanan ini. Layanan tersebut dapat menerima alamat IP perangkat Anda sebagaimana permintaan internet pada umumnya.
  • Hosting (GitHub Pages): berkas aplikasi disajikan melalui GitHub Pages. Saat aplikasi memuat atau memperbarui berkasnya, GitHub dapat menerima alamat IP perangkat Anda sebagaimana permintaan internet pada umumnya.
  • Donasi (Saweria): tautan donasi membuka situs Saweria di luar aplikasi. Pemrosesan data di sana tunduk pada kebijakan Saweria.

4. Informasi kesehatan

Menu pada kategori medis hanya memberikan perkiraan umum dan bukan saran, diagnosis, atau pengobatan medis. Konsultasikan dengan tenaga kesehatan profesional untuk keputusan medis. Data yang Anda masukkan tidak disimpan di server kami.

5. Hiburan semata

Hasil pada menu bertema ramalan, kepribadian, dan sejenisnya dibuat untuk hiburan dan tidak dapat dijadikan dasar keputusan penting.

6. Anak-anak

Aplikasi ini tidak ditujukan bagi anak di bawah 12 tahun dan kami tidak dengan sengaja mengumpulkan data dari mereka.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal pembaruan terbaru tercantum di bagian atas halaman.
